# QuestieTrace Correction Output Format

This document describes the Lua output format produced by the QuestieTrace correction writer (`tools/corrections-extractor/src/core/corrections-writer.ts`).

## Overview

The correction writer generates Questie "forever*Traces" modules - sparse override tables that layer on top of Questie's base database. Each module is a Lua file that returns a table mapping entity IDs to only the fields that were actually observed/extracted.

### File Naming

- Module name: `Forever{Entity}Traces` (e.g., `ForeverQuestTraces`, `ForeverNpcTraces`)
- Filename: `forever{Entity}Traces.lua` (e.g., `foreverQuestTraces.lua`, `foreverNpcTraces.lua`)

### Output Structure

```lua
---@class ForeverQuestTraces
local ForeverQuestTraces = QuestieLoader:CreateModule("ForeverQuestTraces")

---@type QuestieDB
local QuestieDB = QuestieLoader:ImportModule("QuestieDB")

-- Generated by QuestieTrace extract (tools/corrections-extractor)
-- Source trace files: N
-- Sessions aggregated: M
-- Generated at: 2024-01-01T00:00:00.000Z
function ForeverQuestTraces:Load()
    local questKeys = QuestieDB.questKeys

    return {
        [questID] = {
            [questKeys.fieldName] = value,
            ...
        },
        ...
    }
end
```

## Entity: Quest

**Module:** `ForeverQuestTraces` / `foreverQuestTraces.lua`
**Keys table:** `QuestieDB.questKeys`

### Fields Exported

| Internal Field | Output Key | Type | Description |
|---|---|---|---|
| `name` | `questKeys.name` | string | Quest name |
| `questLevel` | `questKeys.questLevel` | int | Quest level |
| `requiredLevel` | `questKeys.requiredLevel` | int | Required player level (clamped to questLevel) |
| `zoneOrSort` | `questKeys.zoneOrSort` | int | AreaTable ID (>0) or QuestSort ID (<0) |
| `objectivesText` | `questKeys.objectivesText` | table | Quest description text |
| `triggerEnd` | `questKeys.triggerEnd` | table | Quest end trigger data |
| `objectives` | `questKeys.objectives` | table | Positional table: `{creatureObj, objectObj, itemObj, ...}` |
| `startedBy` | `questKeys.startedBy_add` | table | **Positional:** `{creatures[], objects[], items[]}` |
| `finishedBy` | `questKeys.finishedBy_add` | table | **Positional:** `{creatures[], objects[]}` |
| `questStarts` | `questKeys.questStarts_add` | table | Quest IDs this quest starts (breadcrumbs) |
| `questEnds` | `questKeys.questEnds_add` | table | Quest IDs this quest finishes |
| `requiredRaces` | `questKeys.requiredRaces` | bitmask | Required races |
| `requiredClasses` | `questKeys.requiredClasses` | bitmask | Required classes |
| `preQuestGroup` | `questKeys.preQuestGroup` | table | Group prerequisites |
| `preQuestSingle` | `questKeys.preQuestSingle` | table | Single prerequisites |
| `childQuests` | `questKeys.childQuests` | table | Child quests |
| `exclusiveTo` | `questKeys.exclusiveTo` | table | Mutually exclusive quests |
| `nextQuestInChain` | `questKeys.nextQuestInChain` | int | Next quest in chain |
| `breadcrumbForQuestId` | `questKeys.breadcrumbForQuestId` | int | Quest this breadcrumb leads to |
| `breadcrumbs` | `questKeys.breadcrumbs` | table | Breadcrumb quest IDs |

### Quest Output Examples

**Quest with startedBy (NPC + item):**
```lua
[12345] = {
    [questKeys.name] = "A Threat Within",
    [questKeys.questLevel] = 30,
    [questKeys.requiredLevel] = 25,
    [questKeys.zoneOrSort] = 141,
    [questKeys.startedBy_add] = {{33},nil,{45}},  -- creatures={33}, objects=nil, items={45}
    [questKeys.finishedBy_add] = {{40},{12}},  -- creatures={40}, objects={12}
    [questKeys.objectives] = {{{504},{95}},{{589}},nil},
}
```

**Quest with only creatures for startedBy:**
```lua
[12345] = {
    [questKeys.name] = "Simple Quest",
    [questKeys.startedBy_add] = {{276171}},  -- creatures only, trailing nil positions omitted
    [questKeys.finishedBy_add] = {{276171}},
}
```

**Quest with objectives (creature kill):**
```lua
[207] = {
    [questKeys.objectives] = {{{2005},{2006},{2007},{2008}}},  -- position 1 = creature objectives
}
```

**Quest with objectives (object interaction):**
```lua
[38] = {
    [questKeys.objectives] = {nil,{{729},{730},{731},{732}}},  -- position 2 = object objectives
}
```

**Quest with objectives (item collection):**
```lua
[207] = {
    [questKeys.objectives] = {nil,nil,{{2005},{2006},{2007},{2008}}},  -- position 3 = item objectives
}
```

## Entity: NPC

**Module:** `ForeverNpcTraces` / `foreverNpcTraces.lua`
**Keys table:** `QuestieDB.npcKeys`

### Fields Exported

| Internal Field | Output Key | Type | Description |
|---|---|---|---|
| `name` | `npcKeys.name` | string | NPC name |
| `minLevel` | `npcKeys.minLevel` | int | Minimum level |
| `maxLevel` | `npcKeys.maxLevel` | int | Maximum level |
| `zoneID` | `npcKeys.zoneID` | int | Most common zone |
| `spawns` | `npcKeys.spawns` | table | Zone -> coordinates mapping |
| `questStarts` | `npcKeys.questStarts_add` | table | Quest IDs this NPC starts |
| `questEnds` | `npcKeys.questEnds_add` | table | Quest IDs this NPC finishes (positional: `{creatures[], objects[]}`) |

### NPC Output Examples

**NPC with questEnds:**
```lua
[276171] = {
    [npcKeys.name] = "Warlord Goretooth",
    [npcKeys.questEnds_add] = {{10},{20, 30}},  -- creatures={10}, objects={20,30}
}
```

**NPC with only object questEnds:**
```lua
[12345] = {
    [npcKeys.questEnds_add] = {nil,{50}},  -- no creatures, objects={50}
}
```

## Positional Table Format

The following fields use **positional tables** (arrays where position matters, not key names):

| Field | Positions | Description |
|---|---|---|
| `startedBy` / `startedBy_add` | 1=creatures, 2=objects, 3=items | Quest starters |
| `finishedBy` / `finishedBy_add` | 1=creatures, 2=objects | Quest finishers |
| `questEnds` / `questEnds_add` (NPC/Object) | 1=creatures, 2=objects | NPC/Object quest ends |
| `objectives` | 1=creature, 2=object, 3=item, 4=reputation, 5=killCredit, 6=spell | Quest objectives |

**Rules:**
- Missing positions become `nil` to maintain index alignment
- Trailing empty positions are omitted entirely
- Each objective ID is wrapped in its own table: `{{id1},{id2}, ...}`

---

## Notes

1. **Sparse output**: Only fields with actual observations are included. No defaults are written.
2. **Field name mapping**: Internal field names (e.g., `startedBy`) map to output keys with `_add` suffix (e.g., `questKeys.startedBy_add`).
3. **Trailing nil omission**: Per Questie convention, trailing empty/nil positions in positional tables are dropped.
4. **Array wrapping**: Flat arrays of numbers (objective IDs) are wrapped: `{1,2,3}` → `{{1},{2},{3}}`.
